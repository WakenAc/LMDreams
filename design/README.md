# Ficheiros de origem (não publicados)

Esta pasta guarda os originais em alta resolução. **Não é copiada para o
site publicado** — só a pasta `public/` é.

- `originais/logotipo.png` — logótipo oficial da LMDreams.
- `originais/hf_*.png` — fotografias em resolução máxima.

As versões usadas no site são geradas a partir daqui e vivem em
`public/images/` (WebP, redimensionadas). Ver README principal, secção
"Imagens".
